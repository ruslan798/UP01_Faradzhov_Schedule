## 📌 Описание проекта и выполненный функционал

Приложение разработано на платформе **WPF (.NET 10 / C#)** с использованием **Entity Framework Core**, архитектуры словарей стилей и компонентной базы согласно методическим указаниям практики.

### Реализованные шаги (по методичке):
- **Шаг 1. Создание БД:**
  - База данных `DB_Faradzhov_Schedule` в третьей нормальной форме (3НФ), 8 связанных таблиц: `user_account`, `department`, `teacher`, `classroom`, `study_group`, `subject`, `time_slot`, `schedule_item`.
  - Поддержка каскадного удаления (`ON DELETE CASCADE`) для обеспечения ссылочной целостности.
- **Шаг 2. Разметка MainWindow (Grid 50 / * / 40):**
  - Верхняя панель: кнопка «Назад», динамический заголовок страницы, переключатель тем, информация о сессии и кнопка «Выход».
  - Центральный навигационный контейнер `Frame` (`MainFrame`) со скрытыми системными элементами перехода.
  - Нижняя панель: дата и время, обновляемые каждую секунду через `DispatcherTimer`, статус БД.
  - Подтверждение при закрытии приложения (`Window_Closing`).
- **Шаг 3. Подключение словарей стилей и смена тем:**
  - Фирменный стиль `Dictionary.xaml` (палитра `#0198AF`, `#233E76`, `#F3F3F3`, `#FFFFFF`, шрифты Segoe UI / Open Sans).
  - Собственный альтернативный словарь тем `CustomTheme.xaml` (контрастная тёмная тема `#1E242B`, `#00B4D8`).
  - Динамическое переключение оформления в реальном времени.
- **Шаг 4. Авторизация пользователей (`AuthPage`):**
  - Проверка логина и пароля, всплывающие подсказки `ToolTip`, плейсхолдеры.
  - Ролевой доступ: `Admin` (полный доступ к CRUD и отчетам) и `User` (просмотр расписания и преподавателей).
- **Шаг 5. Защитная капча:**
  - Автоматическая активация генерации 6-значной буквенно-цифровой капчи после 3 неверных попыток входа.
  - Блокировка системных операций буфера обмена (Copy, Cut, Paste) через `PreviewExecuted`.
  - Блокировка кнопки входа до корректного прохождения капчи.
- **Шаг 6. Регистрация пользователей (`RegPage`):**
  - Валидация полей, проверка уникальности логина.
  - Проверка сложности пароля (не менее 6 знаков, наличие цифры и латинских букв).
  - Проверка совпадения подтверждения пароля.
- **Шаг 7. Хеширование паролей:**
  - Необратимое криптографическое хеширование алгоритмом SHA-1 (`SecurityHelper.GetHash`) перед записью в БД и сверка хешей при входе.
- **Шаг 8. Страница расписания и каталог преподавателей (`UserPage`):**
  - Фильтрация расписания по дню недели, типу недели (Все / Числитель / Знаменатель), типу занятия (только лекции).
  - Мгновенный поиск по группе, дисциплине, преподавателю, аудитории.
  - Сортировка по дням недели, группе, предмету, преподавателю.
  - Счётчик «Найдено X из Y».
  - Карточки преподавателей с фотографиями (`ListView` + `WrapPanel`).
  - Просмотр аудиторного фонда.
- **Шаг 9. Панель администратора (`AdminPage`):**
  - 4 раздела: Расписание, Преподаватели, Учебные группы, Аудитории.
  - Быстрый переход к аналитическим отчетам.
- **Шаг 10. CRUD-операции:**
  - Добавление и редактирование занятий (`AddScheduleItemPage`) с **автоматическим контролем пересечений** (проверка занятости аудитории, преподавателя и группы в выбранный день и пару!).
  - Добавление преподавателей (`AddTeacherPage`).
  - Каскадное удаление данных с подтверждением действия.
- **Шаг 11. Смена пароля (`ChangePassPage`):**
  - Сверка текущего пароля, валидация сложности нового пароля и обновление SHA-1 хеша в базе данных.
- **Шаг 12. Диаграммы LiveCharts (`DiagrammPage`):**
  - Столбчатые (`ColumnSeries`), круговые (`PieSeries`) и линейные (`LineSeries`) графики.
  - Анализ педагогической нагрузки, загруженности по дням недели и структуре занятий.
- **Шаг 13. Экспорт в Microsoft Word (.docx):**
  - Полноформатная сводная ведомость расписания через `DocumentFormat.OpenXml` с титульными данными, шапкой и колонтитулами.
- **Шаг 14. Экспорт в Microsoft Excel (.xlsx):**
  - Формирование отчета через `ClosedXML`: лист расписания и лист педагогической нагрузки с **автоматическими формулами суммирования `=SUM(...)`**, границами и заливкой ячеек.
- **Экспорт в Adobe PDF (.pdf):**
  - Генерация официального расписания на семестр через `PdfSharpCore` в ландшафтной ориентации с табличной сеткой.
